# Папка «Мои сертификаты»

Сюда кладутся сертификаты, грамоты и дипломы, которые показываются на сайте
в разделе «Опыт» → «Мои сертификаты».

Подходят файлы: `.jpg`, `.jpeg`, `.png`, `.webp`, `.pdf`.

## Как добавить файл
1. Положить файл в эту папку.
2. Дать понятное имя — оно станет подписью на сайте
   (например: `Курсы повышения квалификации ФГОС 2024.pdf`).
3. Выполнить `npm run deploy` — сайт соберётся и опубликуется.

## Порядок на сайте
Файлы идут по алфавиту (цифры учитываются как числа). Чтобы задать порядок,
начните имя с номера: `01 Диплом.pdf`, `02 Курсы 2023.pdf`, `10 Грамота.jpg`.

## Советы
- Фото с телефона лучше уменьшить до ~1600 px по длинной стороне
  (файл до 1 МБ) — так сайт открывается быстрее.
- PDF — до 5 МБ.
- Не публикуйте документы с паспортными данными, СНИЛС, ИНН, номерами
  счетов, домашним адресом: на сертификатах такие сведения нужно закрыть
  или выбрать вариант документа без них.
